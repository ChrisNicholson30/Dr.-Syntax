Version control

Diff hunk fills sit behind code, so they carry the same readability contract as a selection: Zed's own 0.16 fill opacity is used as the cap, with the solver free to pull it back if a token would drop below 3.5:1.

Vim and Helix modes

A mode chip carries its own label, so the contract is the label against the chip rather than against the editor. Each of the eight modes gets a neutral solved to 7:1 on its own background — which flips direction on the light variant.
