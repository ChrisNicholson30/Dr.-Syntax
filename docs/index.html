Dr. Syntax

The syntax plane

One lightness for all eight hues, so nothing glows brighter than its neighbours. The plane itself is solved — the lightness that maximises mean reachable chroma subject to the contrast floor — not chosen. Chroma varies by hue because sRGB simply holds more of some hues than others; lightness is what must stay constant.

Why Light is not Dark inverted

Maximum chroma reachable at each variant's own lightness plane. At the lightness AAA demands on a light background, two regions of sRGB collapse: around 60–120° and 165–240°, colour can only reach roughly 0.08 chroma, which renders as mud. A naive inversion drops tokens straight into them. The dots mark where the Light variant actually sites its eight hues.

Install

Zed loads themes from an extension directory. Until Dr. Syntax is in the extension store, install it as a dev extension — same result, one extra step.

1 · Clone

git clone https://github.com/ChrisNicholson30/Dr.-Syntax

2 · Load it

cmd+shift+P → zed: install dev extension → choose the cloned folder.

3 · Pick a variant

cmd+shift+P → theme selector: toggle → Dr. Syntax Dark, OLED or Light.

Every claim on this page is reproducible from a checkout. Both scripts are standard-library Python and exit non-zero on failure:

python3 tools/build_theme.py --check   # 44 contrast assertions per variant
python3 tools/validate_theme.py        # key coverage + 4,092 overlay measurements
